# Bundled Inter

`InterVariable.woff2` is the upright Inter variable webfont (weights 100–900),
downloaded from the official Inter repository on 2026-09-22:

https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2

Distributed under the SIL Open Font License; see `LICENSE.txt` alongside it.
The number and family-pack cards use `VNW Card Inter` to avoid affecting typography
elsewhere on the site or depending on the external Google Fonts request.
